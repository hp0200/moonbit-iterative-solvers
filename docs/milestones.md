# 里程碑与范围

本文是路线图文档。除“当前交付范围”外，其它条目都不是当前发布承诺。实现必须按本文范围推进，不得用未列出的算法填满接口。

## 当前交付范围

当前交付包含以下六项：

1. 泛型能力层。
2. 迭代工作区。
3. 共轭梯度 CG。
4. Jacobi 预条件。
5. BiCGSTAB，包括转置残差点积路径。
6. 两个可运行示例：SIR 单步与 PageRank 稳态。

wasm/js 导出层与其它算法不属于当前交付承诺。

### 1. 泛型能力层

完成条件：

- 独立 `FieldSafe` trait，只含安全除法 `div_safe`，不继承 `Ring`。
- 泛型代数组件使用 `[T : Ring + FieldSafe]` 多重约束。
- `Double` 诊断量、`ToDouble` 范数桥接与静态分派所需的类型边界。
- 整数不实现 `FieldSafe`。

### 2. 迭代工作区

完成条件：

- 输入只读、输出独立的迭代状态管理。
- 泛型工作向量与 `Double` 标量诊断量分离。
- 自别名、NaN 传播、错误退出与工作区生命周期有明确契约。
- 不包装或复制上游稀疏存储。

### 3. 共轭梯度 CG

完成条件：

- 包级求解入口，例如 `cg_solve`。
- 支持位置参数与无预条件路径。
- 维度检查、breakdown 识别、迭代超限与方法前提失败均返回错误值。
- 收敛判断使用运算符形式，不使用 `compare`。

### 4. Jacobi 预条件

完成条件：

- 通过静态 enum 选择 Jacobi 路径。
- 对角主元不可安全求逆时返回错误，不 panic。
- 与无预条件路径共享同一求解工作区与错误语义。

### 5. BiCGSTAB

完成条件：

- 包级入口 `bicgstab_solve`，支持无预条件与 Jacobi 路径。
- 固定阴影残差，使用上游 `transpose` 与转置点积恒等式。
- `rho`、`alpha`、`omega` 与 `beta` 的安全除法失败均返回错误值。
- 非对称已知系统、零 `rho` 与维度错误均有测试覆盖。

### 6. 可运行示例

完成条件：

- `examples/sir_step.mbt` 构造 `(I - dt A)` 形式的三阶 SPD 系统并调用 `cg_solve`。
- `examples/pagerank.mbt` 构造五节点转移矩阵并调用 `bicgstab_solve` 求稳态。
- 两个入口包均可通过 `moon run` 实际执行。

## 本期完成定义

- 当前六项能力通过正确性测试与错误路径测试。
- 公开 API 不含上游矩阵包装类型。
- 求解失败均可由返回值处理，不依赖 panic。
- 文档与实现范围一致，不出现未实测性能声明。
- 发布检查表全部通过后才允许发布。

## 下一阶段

下一阶段的核心条目为：

- `Float` 实例化。
- SSOR 预条件。
- wasm/js 导出层，按具体类型逐项实例化核心入口。

下一阶段的可选算法为：

- GMRES；只有在四项核心条目、错误语义与测试覆盖不被挤压时才进入实现。

GMRES 仅作为路线图候选存在，不属于本期承诺；若排期不足，应首先砍掉此类可选算法，而不是降低 CG/Jacobi 的正确性或错误处理。

## 砍单顺序

范围不足时按以下顺序收缩：

1. 砍掉当前交付之外的可选算法（包括 GMRES 及其它未列入的求解方法）。
2. 砍掉未来新增示例、基准数据集广度与非必要文档扩写。
3. 砍掉下一阶段核心条目中的后置项，按导出层、SSOR、Float 的依赖与验证成本评估后执行。

任何情况下都不砍核心四项：泛型能力层、迭代工作区、CG、Jacobi 预条件。BiCGSTAB 与示例已进入当前交付，不得用占位实现替换。

不得用占位函数、返回固定结果、跳过错误路径或放宽残差断言来“保留”四项名义；此类做法等同砍掉对应能力。

## 阶段依赖

```text
泛型能力层
    |
    +--> 迭代工作区
    |        |
    +--------+--> CG
                 |
                 +--> Jacobi 预条件

本期四项稳定
    |
    +--> BiCGSTAB（含本库转置乘积）
    +--> SIR / PageRank 示例
    +--> Float 实例化
    +--> SSOR 预条件
    +--> wasm/js 导出层
```

Jacobi 与 CG 的顺序可按实现细节微调，但两者都必须复用已冻结的能力层与工作区契约。导出层必须晚于核心数值路径，且与泛型核心物理分离。

- 上游矩阵包装类型。
- trait object 预条件分派。
- 整数求解器实例化。
- 未经验证的 wasm/js 导出入口。
