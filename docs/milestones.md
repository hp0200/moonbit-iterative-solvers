# 里程碑与范围

本文是路线图文档。除“本期范围”外，其它条目都不是当前脚手架或当前发布的交付承诺。实现阶段必须按本文范围推进，不得用未列出的算法填满接口。

## 本期范围：四项不可砍

本期等于以下四项能力：

1. 泛型能力层。
2. 迭代工作区。
3. 共轭梯度 CG。
4. Jacobi 预条件。

四项之外的算法、导出层与额外示例不属于本期承诺。

### 1. 泛型能力层

完成条件：

- 独立 `FieldSafe` trait，只含安全除法 `div_safe`，不继承 `Ring`。
- 求解器使用 `[T : Ring + FieldSafe]` 多重约束。
- `Double` 诊断量、`ToDouble` 范数桥接与静态分派所需的类型边界。
- 整数不实现 `FieldSafe`。

### 2. 迭代工作区

完成条件：

- 输入只读、输出独立的迭代状态管理。
- 泛型工作向量与 `Double` 标量诊断量分离。
- 自别名、NaN 传播、错误退出与工作区生命周期有明确契约。
- 不包装或复制上游稀疏存储。

### 3. 共轭梯度 CG

完成条件：

- 包级求解入口，例如 `cg_solve`。
- 支持位置参数与无预条件路径。
- 维度检查、breakdown 识别、迭代超限与方法前提失败均返回错误值。
- 收敛判断使用运算符形式，不使用 `compare`。

### 4. Jacobi 预条件

完成条件：

- 通过静态 enum 选择 Jacobi 路径。
- 对角主元不可安全求逆时返回错误，不 panic。
- 与无预条件路径共享同一求解工作区与错误语义。

## 本期完成定义

- 四项能力通过差分测试与错误路径测试。
- 公开 API 不含上游矩阵包装类型。
- 求解失败均可由返回值处理，不依赖 panic。
- 文档与实现范围一致，不出现未实测性能声明。
- 发布检查表全部通过后才允许发布。

## 下一阶段

下一阶段的核心条目为：

- `Float` 实例化。
- SSOR 预条件。
- BiCGSTAB，包括本库自行实现的转置矩阵-向量乘积。
- wasm/js 导出层，按具体类型逐项实例化核心入口。

下一阶段的可选算法为：

- GMRES；只有在四项核心条目、错误语义与测试覆盖不被挤压时才进入实现。

GMRES 仅作为路线图候选存在，不属于本期承诺；若排期不足，应首先砍掉此类可选算法，而不是降低 CG/Jacobi 的正确性或错误处理。

## 砍单顺序

范围不足时按以下顺序收缩：

1. 砍掉本期之外的可选算法（包括 GMRES 及其它未列入四项的求解方法）。
2. 砍掉示例数量、基准数据集广度与非必要文档扩写。
3. 砍掉下一阶段核心条目中的后置项，按导出层、BiCGSTAB、SSOR、Float 的依赖与验证成本评估后执行。

任何情况下都不砍本期四项：泛型能力层、迭代工作区、CG、Jacobi 预条件。

不得用占位函数、返回固定结果、跳过错误路径或放宽残差断言来“保留”四项名义；此类做法等同砍掉对应能力。

## 阶段依赖

```text
泛型能力层
    |
    +--> 迭代工作区
    |        |
    +--------+--> CG
                 |
                 +--> Jacobi 预条件

本期四项稳定
    |
    +--> Float 实例化
    +--> SSOR 预条件
    +--> BiCGSTAB（含本库转置乘积）
    +--> wasm/js 导出层
```

Jacobi 与 CG 的顺序可按实现细节微调，但两者都必须复用已冻结的能力层与工作区契约。导出层必须晚于核心数值路径，且与泛型核心物理分离。

## 范围外

以下内容不在本期范围：

- 稀疏矩阵存储实现。
- 数值诊断工具重实现。
- 上游矩阵包装类型。
- trait object 预条件分派。
- 整数求解器实例化。
- 未经验证的 wasm/js 导出入口。
- 未经实测的加速比、产物体积或收敛率承诺。
