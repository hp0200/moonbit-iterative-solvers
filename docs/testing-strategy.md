# 测试策略

测试目标是固定契约，而不是证明某个算法在任意输入上收敛。当前仓库包含 11 个测试，
全部使用 MoonBit 标准测试设施，不依赖外部数值库。

## 覆盖范围

### 诊断

- 稳定错误码可通过公开读取函数取得。
- `context` 是结构化键值数据。
- Agent 建议与解释字段非空。

### 独立验证

- 精确解得到有效报告。
- 错误解得到无效报告且残差大于零。
- 维度错误返回 `DIMENSION_MISMATCH`，简版入口不 panic。
- NaN 输入得到无效报告而不是 NaN 成功结果。
- 测试断言残差满足容差，不断言残差随迭代单调下降。

### 参考 CG

- 小型对称正定系统收敛，并通过独立验证器检查。
- 零矩阵返回 `SINGULAR_PIVOT`。
- 右端项维度错误返回 `DIMENSION_MISMATCH`。
- NaN 矩阵返回 `NON_FINITE_INPUT`。
- 矩形矩阵返回 `NON_SQUARE_MATRIX`。

## 断言原则

- 错误路径按稳定错误码断言，不只断言“出现错误”。
- 成功路径用验证器重算残差，不信任求解器循环内部的残差变量。
- 数值容差与实现常量一致，避免测试放宽生产契约。
- 不在测试中引入外部矩阵库或复制第三方 fixture。

## 运行方式

```bash
moon check
moon test
```

CI 还会对 `wasm-gc`、`js`、`native` 执行检查与测试，并运行 `moon fmt --check`。当前结果
以实际 CI 或本地命令输出为准，不把“工作流文件存在”当成本地已通过证据。

## 后续测试

若增加新的诊断构造器、验证谓词或参考算法，应同步增加：

- 成功结果的独立残差断言。
- 每种新增数值失效的错误码与上下文断言。
- 非有限输入、自别名或输入不变性等边界契约。

本期没有性能基准结论；测试不用于伪造吞吐量或加速比。
