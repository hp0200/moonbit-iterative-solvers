# 基准计划

## 当前状态

本期没有记录或发布任何性能数字、加速比、收敛率或产物体积。参考 CG 以可读性和安全失败
为优先，不作为高性能承诺。

## 若后续执行基准

只有实际运行后才允许写入结论，并至少记录：

- MoonBit 工具链版本与提交标识。
- 目标后端：`wasm-gc`、`js` 或 `native`。
- 硬件/运行环境与操作系统。
- 矩阵阶数、稀疏度或稠密分布、条件特征与数据来源。
- 完整命令与可复现输入。
- 每轮耗时、迭代次数、最终验证残差与失败次数。

## 指标边界

- 求解时间必须与独立验证结果一起报告，避免快速但错误的解。
- 不得把单次小矩阵运行外推为通用性能。
- 不得把参考 CG 与优化库对比后声称本库“更快”。
- 若没有基准，README、发布说明与定位文档必须保持无数字状态。

## 基准不改变契约

增加基准不得引入外部包、放宽零依赖约束或把基准结果变成功能承诺。若未来需要与其它库
做差分测试，应先定义可选测试依赖策略并新增 ADR。
