# 打包与发布检查表

本清单用于实现阶段结束后的发布准备。当前仓库只有脚手架，没有 CG、Jacobi、工作区或泛型能力实现，因此当前状态不得发布。

## 发布前置门槛

- [ ] 本期四项能力均已实现：泛型能力层、迭代工作区、CG、Jacobi 预条件。
- [ ] 差分测试、错误路径测试、输入不变性与自别名测试全部通过。
- [ ] 公开 API 与 `docs/milestones.md` 的本期范围一致，没有用占位函数冒充能力。
- [ ] 所有数值失效通过返回值报告，不依赖 panic。
- [ ] 当前提交在目标 MoonBit 工具链上可构建、可格式化、可测试。

任何一项未满足都不得进入发布流程。

## 依赖与版本

- [ ] `moon.mod` 只包含 `hp0200/moonbit-sparse-math` 与 `Luna-Flow/luna-generic` 两个第三方依赖。
- [ ] 开发期由仓库根目录 `moon.work` 将同级 `moonbit-sparse-math` 纳入工作区，`moon.mod` 中保留精确版本号依赖：

  ```text
  import {
    "hp0200/moonbit-sparse-math@0.2.1",
    "Luna-Flow/luna-generic@0.4.0",
  }
  ```

  工作区存在同名模块时，上游版本部分会解析为同级本地源码。

- [ ] 发布版本必须与上游实际发布到 registry 的版本一致，不得指向本地提交或未发布快照。
- [ ] `Luna-Flow/luna-generic` 保持精确版本号，本期为 `"0.4.0"`；不使用浮动版本范围。
- [ ] 发布前确认 `moon.mod` 中的上游版本确实存在于 registry，且不再依赖工作区本地解析。
- [ ] 不把仓库根目录 `moon.work` 的同级目录假设当成发布依赖；工作区只用于本地联调。
- [ ] 确认两个第三方依赖的许可证与本库 Apache-2.0 发布兼容；本文件不替代对第三方许可证原文的核查。

## 包结构与依赖方向

- [ ] `src/algebra`、`src/precond`、`src/workspace`、`src/solvers`、`src/wasm` 的依赖关系符合 `docs/architecture.md`。

- [ ] `src/precond` 只依赖 `algebra` 与 `workspace`，`src/solvers` 复用其公开能力。

- [ ] 上游对本库零依赖，发布过程不要求上游修改以适配本库。

## 数值与错误语义

- [ ] 残差范数、容差、右端项范数与 breakdown 阈值均为 `Double`。
- [ ] 范数通过 `ToDouble` 进入 `Double` 计算。
- [ ] 收敛判断使用 `<=`、`<` 等运算符，不使用 `compare`。
- [ ] 奇异主元、内积 breakdown、迭代超限、维度不匹配、方法前提不满足均有可区分的错误值。
- [ ] NaN 进入迭代时以迭代超限退出，不 panic。
- [ ] `div_safe` 除零返回 `None`，不执行不安全除法。
- [ ] 输入数组只读，成功解与输入分离；自别名契约有测试与文档。
