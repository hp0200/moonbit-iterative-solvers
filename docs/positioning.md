# 生态定位

## 项目身份

`moonbit-iterative-solvers` 是 AI Agent 友好的零依赖数值诊断与验证引擎。它面向 MoonBit
生态中的安全数值边界，而不是高性能稀疏线性代数套件。

## 解决的问题

Agent 调用数值接口时，最危险的输出不是显式异常，而是：

- 静默产生 `NaN` 或无穷值。
- 奇异系统继续迭代并返回看似正常的结果。
- 迭代预算耗尽后把未收敛结果误报为成功。
- 求解器自报残差与真实残差不一致。

本库分别用结构化诊断、有限性检查与独立残差验证处理这些问题。

## 三个能力支柱

### 零依赖沙箱

`moon.mod` 不声明外部依赖，源码不 import 其它包。调用方无需配置上游矩阵库、泛型算术
包或本地工作区。固定包边界适合 Wasm 沙箱与 Agent 运行时。

### 结构化诊断

`SolverDiagnostic` 把失败转换成稳定错误码、解释、Agent 建议和键值上下文。Agent 可以
直接按错误码分支，而不必解析人类语言或宿主异常。

### 独立验证

`VerificationReport` 由验证器独立重算 `b - Ax` 得到。即使不使用本库求解器，也可以用它
检查其它来源的 `x`；反过来，求解结果也应经过验证后再被 Agent 接受。

## 目标用户

- 在 MoonBit Agent 工具链中需要安全数值边界的开发者。
- 需要对候选解做独立质量检查的工作流。
- 需要把数值失败转换成可重试、可升级、可记录事件的应用。
- 需要在 Wasm 沙箱中避免额外依赖配置的集成方。

## 非目标

- 不提供稀疏存储或格式转换。
- 不提供生产级大型系统求解器。
- 不提供预条件、并行计算、FFI 或零拷贝承诺。
- 不与 `hp0200/moonbit-sparse-math` 或 `Luna-Flow/luna-generic` 建立依赖关系。
- 不发布未经实测的性能数字、加速比或产物体积。

## 演进边界

本库允许后续增加更多诊断契约、验证谓词或参考算法，但任何会引入外部依赖、改变零依赖
定位或扩大公开算法承诺的变更，都必须先新增 ADR。旧 ADR-1 至 ADR-6 不再约束当前实现。
